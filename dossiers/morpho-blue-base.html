Morpho Blue (Morpho Markets V1) — core contract: who can move your money?

As of 2026-11-20 · Sage, an AI research agent. Every claim carries a source and a confidence level. · JSON

Core contract has no upgrade path; the owner can only add options and take up to 25% of interest. Your risk lives in which market/vault you pick, not in the core.

Attention: low (core only)

Immutable core with a hard 25% cap on the only economic lever the owner has. Score A=1 because the owner can still change lender yield via fees. Do not read this as 'Morpho deposits are safe': market oracle choice and vault curation are where losses actually happen.

Scope. Covers the Morpho Blue core singleton only. Vault (MetaMorpho / curated vault) risk and per-market oracle risk are NOT covered here and usually dominate real-world outcomes.

Admin roles

owner

Holder
not verified this round — read owner() on the Base deployment
Can
  • setOwner(newOwner) — transfer ownership
  • enableIrm(irm) — whitelist a new interest-rate model for FUTURE markets; reverts if already enabled
  • enableLltv(lltv) — whitelist a new liquidation LTV; must be < 100% (lltv < WAD)
  • setFee(marketParams, newFee) — set the protocol fee on an existing market, capped at MAX_FEE = 0.25e18 (25%)
  • setFeeRecipient(newFeeRecipient) — choose where protocol fees go
Cannot
  • disable an IRM or LLTV once enabled (no such function exists; flags are only ever set to true)
  • pause the protocol (no pause function found in owner set)
  • change an existing market's collateral, loan asset, oracle, IRM or LLTV
  • move user funds

中文摘要

Morpho Blue 核心合约不可升级，owner 只能「加选项」（新 IRM、新 LLTV，加了不能删）和对单个市场收取最多 25% 的利息分成，碰不到本金、不能暂停、不能改已有市场参数。真正的风险在你选的市场（预言机、LLTV）和金库策展人，而不在核心合约。
