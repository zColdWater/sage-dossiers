手里还有旧 AERO、VELO、veNFT 或 Aerodrome LP？

Aero 已在 2026 年 10 月 22 日取代 Aerodrome 和 Velodrome。如果你还没升级，这一页按顺序列出该做的事，每条事实都附官方来源。免费，不加载任何外部网站的内容。

最重要的五件事

  1. 不会自动转换。 代币、锁仓、流动性都要你自己到官方升级入口操作。
  2. 旧版排放已经停了。 Aero 上线时，Aerodrome 和 Velodrome 的所有 gauge 都已停用，质押在旧池子里的 LP 不会再拿到新排放。
  3. 没有截止日。 不过官方说旧前端以后可能关闭。谁催你「今天不升级就没了」，说的都不是官方页面上的内容。
  4. 不可逆。 升级后不能再换回去。
  5. 比例是固定的。 旧 AERO 按 1:1 换成新 AERO；每个 VELO 换 0.044 个 AERO（官方说明这个比例是按预计供应量算的）。

来源: https://aero.xyz/aero-upgrade/

你的步骤（按顺序）

你手里有什么？

把符合的都勾上，下面就只显示你需要的步骤。都不勾就显示全部。

  1. 只用官方网站，网址自己手动输入。升级入口在 aerodrome.finance 和 velodrome.finance；官方指南是 aerodrome.finance/docs/upgrade 和 velodrome.finance/docs/upgrade；新应用是 app.aero.xyz。私信、评论区回复、广告里的「升级链接」一律别点。 (官方升级中心)
  2. 币在交易所？按交易所的安排来。中心化交易所会自己组织升级，有自己的时间表。先看交易所的公告。 (官方升级中心)
  3. 留一点 ETH 付手续费。Aerodrome 这边升级要 Base 上的 ETH，Velodrome 这边要 OP Mainnet 上的 ETH。升级 veVELO 还要另付一笔跨链消息费，也用 ETH 付。 (官方升级中心)
  4. 多签或合约钱包：先确认收款地址在 Base 上能用。升级后的资产到账在 Base 上。如果收款地址是合约钱包或多签，先确认它在 Base 上存在、能正常使用。转过去就撤不回来。 (官方升级中心)
  5. 先把 veNFT 取回自己的钱包。先从 Relay、金库或其他协议里提出来。升级流程只认你自己钱包里直接持有的 veNFT。 (官方升级中心)
  6. 升级前把奖励全部领掉。升级之后，veNFT 上没领的奖励就找不回来了。升级流程会带你领取，别跳过。 (官方升级中心)
  7. 重置投票。还有有效投票的 veNFT 不能升级。升级流程里包含重置这一步。 (官方升级中心)
  8. 先把 VELO 转回 OP Mainnet。升级流程只识别已经在 OP Mainnet 上的 VELO，在其他链上的 VELO 或 xVELO 要先跨链转回去。Velodrome 的升级在 OP Mainnet 上发起，最后到账在 Base 上。 (官方升级中心)
  9. 把锁仓升级成 sAERO。旧的 veNFT 编号会作废，你会拿到一个新的 sAERO 仓位。剩余锁仓时间会保留，向上取整到下一个整周；永久锁仓会变成最长质押期的 sAERO。 (官方升级中心)
  10. 升级未锁仓的代币。在升级入口操作：AERO 按 1:1 兑换，VELO 按 0.044 兑换成 AERO。 (官方升级中心)
  11. ALM 仓位要手动撤出。由 ALM 管理的仓位不会自动迁移。先撤出来，之后自己管理流动性。 (官方升级中心)
  12. 和 VELO 配对的池子：先撤，再升级 VELO。先撤出仓位，再把 VELO 升级，然后到升级后的池子里重新提供流动性。 (官方升级中心)
  13. 有对应池子就迁移，没有就撤出。不是每个旧池子在 Aero 上都有对应的池子。升级流程给出 1:1 的目标池就直接迁移；没有就手动撤出，愿意的话可以在 Liquidity 页面新建池子。在符合条件的 Aero 池子里提供流动性可以拿到 AERO 奖励。 (官方升级中心)
  14. 签名之前：核对合约地址。钱包让你授权或调用的合约，先和官方 security 页面核对一遍。下面的核对工具收录了主要的迁移合约和核心合约。 (官方 security 页面)

危险信号（Sage 自己的建议，不是官方页面的内容）

  • 通过私信、评论区回复或广告收到的「迁移」「领取」链接。
  • 倒计时，或者「最后期限」。官方明确说了没有截止日。
  • 任何索要助记词或私钥的要求。升级从来不需要这些。
  • 让你把币直接转到某个普通钱包地址，而不是走升级入口。
  • 让你授权一个不在官方 security 页面上的合约，或者只是看起来像的合约。
现在谁控制着 Aero？ 官方 security 页面列了大约 15 个权限角色，另有一个紧急委员会多签，可以关停 gauge、暂停迁移合约，但页面没有公布任何多签地址、签名人或门限。完整的带来源档案见： Aero 控制权档案（英文）
